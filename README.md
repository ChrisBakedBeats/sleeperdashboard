# Sleeper Dashboard

Read-only dashboard for your Sleeper fantasy football leagues (Vite + React + TypeScript). No API key or backend needed.

```
npm install
npm run dev
```

Enter your Sleeper username in the page. It is remembered in your browser.

## Deploy (GitHub Pages)

1. Push this project to the `main` branch of a GitHub repo.
2. In the repo, go to Settings > Pages and set Source to "GitHub Actions".
3. Every push to `main` builds and publishes the site. The link appears in the Actions run and under Settings > Pages.
